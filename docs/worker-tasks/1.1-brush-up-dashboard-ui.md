## 作業の概要

1.0-create-dashboard-ui.md で作成したダッシュボード画面をブラッシュアップしたいです。
以下の改善点を踏まえて実装してください。

### 改善点

#### 1. おすすめメニューの生成タイミングについて

現在、おすすめメニューはトレーニング開始前、常に表示されていますが、これをボタン押下時に生成する形に修正してください。
なので、「トレーニング開始」ボタンは「おすすめメニュー生成」ボタンへ変更お願いします。
現状は Mock なので未実装で構いませんが、最終的にはこのボタンを押下した際に、直近の筋トレメニューと体重・体脂肪率からおすすめメニューを API で取得できるようにする予定です。

#### 2. トレーニング開始時のモーダルについて

このモーダルは「おすすめメニュー生成」ボタンが押下された場合に表示されるモーダルに変更になります。
おすすめメニューの理由について説明してください。

#### 3. トレーニング開始後の登録画面について

現在、登録画面はフォームから実施した筋トレを登録できる形ですが、これを変更したいです。
具体的には。登録画面にはすでにおすすめメニューの種類・回数がセットされており、それにチェックをつけると斜線が引かれる（ToDo リストの Done 状態）となり、実施したことを表現したいです。
追加で実施する場合は、プラスボタンを押下し現在のメニュー登録フォームを表示させて追加できるようにしてください。（こちらもチェックが付けられる状態で追加されます）
最終的にチェックが付いた状態のメニューが、その日に実施したメニューになります。
