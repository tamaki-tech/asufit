## 作業の概要

dashboard 画面の UI を作成してください。
dashboard 画面の仕様は以下のとおりです。

### 画面の目的

この画面は、筋トレ・ランニングなどの運動の記録をつけるための画面です。
あすけんのように、日々の運動記録をつけることができます。

### 画面の仕様について

- 画面上部には日にちが書いてあり、昨日・明日に 1 日ずつ移動できる遷移ボタンが存在します。
- 画面中央には実施した筋トレの記録が表示されます。
- その日のトレーニングは、開始前、開始後の状態が存在します。
  - トレーニング開始前の場合は、画面下部に「トレーニング開始」ボタンが存在します。
  - 画面中央には、筋トレの記録の代わりに、今日のおすすめメニューが表示されます。
  - トレーニング開始ボタンを押すと、モーダルが表され、今日のメニューに関する一言コメントが表示されます。
  - モーダルの開始ボタンを押下すると、モーダルが消えます。
- トレーニング開始後は、トレーニング記録をつけることができるようになります。
- トレーニング記録はおすすめメニューを優先的に付けることが可能ですが、その他の記録もつけることができます。
- トレーニングはプルダウンで選ぶことができます。
  - 腕立て伏せ、腹筋のような筋トレは回数、ダンベルや重量が必要なものは回数に加えて重量を選択できます。
  - ジョギング、バイクなどの有酸素運動は時間または距離で記録できるようにしたいです。
